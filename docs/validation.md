## Устойчивость к HTTP 502/503 при подготовке WikiArt

При проверке по настоящей сети /rows для первых двух страниц huggan/wikiart возвращал 502, а Hub API выдавал 200 и прежнюю закреплённую revision. Недоступность Viewer подтверждена отдельно от работоспособности Hub; полная подготовка данных во время этого сбоя не подтверждалась.

Добавлены шесть ограниченных попыток с паузами 2/4/8/16/30 секунд, обработка Retry-After (включая HTTP-date, ожидание ограничено 60 секундами), видимые сообщения о повторе и явная ошибка при исчерпании попыток. Query-параметры подписанных image URL не выводятся. Постоянные ошибки вроде 404 не повторяются; TLS-проверка сохраняется.

Метаданные страниц при совпадающей revision доступны из постоянного кэша после перерыва более пяти минут; временные URL изображений обновляются отдельно. Правила отбора, seed, конфиг, DATA_VERSION и тестовая выборка не менялись. Шесть CPU-тестов проверяют восстановление после смоделированных 503/502, Retry-After, исчерпание попыток, постоянную ошибку, повторное использование метаданных и запрет подмены revision. Эти тесты обработки HTTP не являются подтверждением доступности удалённого сервиса или GPU-пайплайна.
